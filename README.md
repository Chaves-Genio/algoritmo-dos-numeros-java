# Algoritmos dos Números em Java

Projeto académico desenvolvido para a unidade curricular de Algoritmo e Estrutura de Dados II, do curso de Engenharia Informática do Instituto Politécnico da Universidade Kimpa Vita. 
O trabalho aborda fundamentos da teoria dos números, algoritmos matemáticos e aplicações em criptografia, com implementação em linguagem Java.

# Tema do Trabalho 
Algoritmos dos Números com Implementação em Java

# Algoritmos Implementados
## 1. Máximo Divisor Comum - Cálculo simples do MDC entre dois números inteiros.
## 2. Algoritmo de Euclides - Método eficiente para cálculo do MDC.
## 3. Teste de Primalidade - Verificação de números primos.
## 4. Factorização de Inteiros - Decomposição em factores primos.
## 5. Congruências - Operações de aritmética modular.
## 6. Pequeno Teorema de Fermat - Potência modular e aplicações.
## 7. Teorema Chinês do Resto - Resolução simples de congruências simultâneas.
## 8. Função Totiente de Euler - Cálculo de φ(n).
## 9. Sistema RSA - Exemplo didáctico de cifragem e decifragem.

# Requisitos 
- Java JDK 17 ou superior
- - IntelliJ IDEA, NetBeans ou VS Code
  
# Compilação do Projecto 
Abrir o terminal na pasta src e executar: javac Main.java
